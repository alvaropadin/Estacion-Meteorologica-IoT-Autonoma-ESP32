# Estacion-Meteorologica-IoT-Autonoma-ESP32
Crear una estación meteorológica basada en el microcontrolador ESP32
El objetivo es la medición de diferentes magnitudes físicas (Temperatura, humedad, radiación solar, precipitación, presión atmosférica y velocidad de viento)
con una arquitectura basada en el ESP32 de espresiff.

El proyecto abarcará desde la alimentación(con un panel solar), la adquisición de datos, la transmisión de estos, y el display a traves de una pantalla inalambrica
tambien basada en esp32 y una página web accesible desde un dspositivo movil.
